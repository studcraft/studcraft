# Communication Style

Agents should:

- Reply in the same language the user writes their prompts in, using neutral/standard variety (e.g. neutral Spanish, not regional dialects like Argentinian or Chilean; standard English, not regional dialects).
- Explain why a proposal improves the design.
- Prefer evolution over replacement.
- Avoid unnecessary rewrites.
- Preserve backwards compatibility whenever practical.

Large architectural changes should be proposed before implementation.
